🔴 Fusion 360 API 연동 실패 원인 분석

Fusion 360과 Antigravity 연동 시 발생한 극심한 불만족의 근본적인 기술적 요인 4가지입니다.

1. 상태 의존적(Stateful) COM/C++ Wrapper Structure

Fusion API는 파이썬 전용 설계가 아닌 C++ COM 객체 래퍼입니다. Sketch ➔ Profile ➔ Extrude 연산 시 토폴로지 ID가 변경되거나 구속조건 충돌 시 스크립트가 중단됩니다.

2. Single-Threaded UI Lock & Headless 미지원

Fusion 360 API는 GUI 메인 스레드에 결합되어 있어 백그라운드 샌드박스에서 초당 수십 번 빠른 검증이 불가능하며, 외부 REST 통신 시 UI Freeze/Crash가 유발됩니다.

3. Process Memory Caching Traps (`sys.modules`)

Fusion 360 임베디드 파이썬 인터프리터가 모듈을 메모리에 캐싱하여 AI가 파일 코드를 수정하더라도 이전 바이트코드가 계속 재실행됩니다.

4. Visual Feedback Loop (VLM) 구축 불가

AI가 코드를 작성한 후 3D 뷰포트를 실시간 렌더링하여 이미지로 확인(Vision Verification)하고 스스로 보정하는 Closed-loop 제어가 거의 불가능합니다.

🟢 시장 내 주요 대안 솔루션 전수 조사

Fusion 360 대체 및 연동을 위해 활용 가능한 3D CAD AI 툴 및 프레임워크 생태계입니다.

1. Code-CAD Framework (Build123d / CadQuery) 강력 추천

  • Build123d: 파이썬 컨텍스트 매니저(with BuildPart():) 기반 B-Rep 파이썬 CAD 라이브러리. LLM의 파이썬 코드 생성 및 Scope 추적 환각률 60% 감소.
  • OCP CAD Viewer: VS Code에서 AI가 짠 파이썬 CAD 코드를 실시간 3D 시각화.
  • STEP 100% Export: 생성된 STEP 파일을 Fusion 360, SolidWorks로 100% 정밀 임포트.

2. Commercial API & Enterprise Co-Pilot

  • Zoo (formerly KittyCAD): API-First GPU-native 커널 기반. KCL(KittyCAD Language) 코드로 파라메트릭 B-Rep STEP 직접 생성.
  • Leo AI (getleo.ai): 기계공학 전용 Large Mechanical Model (LMM). B-Rep 데이터 분석 및 파라메트릭 CAD/어셈블리 자동 생성.

3. Open-Source Desktop CAD & MCP Integration

  • FreeCAD + MCP Server (`freecad-mcp`): MCP 서버를 통해 Claude/Antigravity가 FreeCAD를 직접 조종. 완전 오픈소스이므로 Headless 제어가 자유로움.

🔬 학술 연구 및 SOTA 레퍼런스 (2024–2026)

최근 3D CAD AI 분야에서 가장 주목받는 최신 논문 및 벤치마크 레퍼런스입니다.

1. Generative CAD Models

  • Text2CAD (NeurIPS 2024 Spotlight): DeepCAD 데이터셋 기반 170k 모델/660k 어노테이션 구축. 자연어 입력에서 순차적 CAD 피처 트리를 자동 생성.
  • BrepGen (ACM SIGGRAPH 2024 - Autodesk Research): 계층적 트리 구조 및 디퓨전 모델을 사용하여 자유 곡면(Free-form NURBS) B-Rep 지오메트리를 직접 생성.
  • SkexGen (ICML 2022): Sketch-and-extrude 연산을 위상, 지오메트리, 돌출 변형 코드북으로 분리하여 생성.

2. Closed-Loop VLM Verification & Benchmarks

  • CADCodeVerify (ICLR 2025 - SOTA): Code-CAD 생성 후 Multi-view 렌더링 ➔ VLM(Vision LLM)이 시각적 QA 수행 ➔ 코드 자동 수정 Feedback Loop 도입 (Point Cloud 거리를 7.3% 단축).
  • BenchCAD (2026): 17,900개의 검증된 CadQuery 프로그램 기반 최신 멀티모달 벤치마크.
  • CADArena (2026): 복잡한 기계 부품의 STL/STEP 실행 및 워터타이트 생성률을 평가하는 오픈 커뮤니티 벤치마크.

🏆 오픈소스 대회 제출용 AI Agent 프로젝트 기획안

프로젝트 명칭 (가칭): BuildAgent-3D
"Code-CAD (Build123d) & VLM Visual Feedback Closed-Loop 3D CAD Generation Agent"

최신 학술 연구(CADCodeVerify)와 오픈소스 생태계(Build123d)를 결합한 대회용 아키텍처 흐름도입니다.

1

사용자 의도 입력 (User Prompt / 2D Sketch)

자연어 요구사항 (예: "4개의 M4 카운터보어 구멍과 모서리 필렛이 들어간 브래킷 설계해줘") 또는 2D 스케치 이미지 입력.

2

Code-CAD 파이썬 생성 (Antigravity Agent)

LLM이 `Build123d` 컨텍스트 매니저 구문을 활용하여 파라메트릭 파이썬 스크립트 작성.

3

Headless OpenCASCADE Execution Engine

백그라운드 샌드박스에서 1초 만에 코드 실행 ➔ 4면도 PNG 이미지 렌더링 + 체적/Bounding Box JSON 추출 + STEP 파일 생성.

4

VLM Multi-View Visual Inspection & Self-Repair Loop

Gemini Vision 모델이 렌더링된 4면도 PNG 이미지를 시각 검증. 형상 왜곡/구멍 누락 발견 시 코드 수정 패치 피드백을 전달하여 자동 재생성 (최대 3회 반복).

5

Fusion 360 & Commercial CAD Export Bridge

검증 완료된 STEP 파일 및 Build123d 파이썬 코드를 내보내어 Fusion 360, SolidWorks 사용자가 원클릭으로 100% 가져올 수 있도록 제공.

🔑 대회 평가 시 핵심 경쟁력

  1. 완벽한 파이썬 오픈소스 독립성: 무거운 상용 CAD GUI 프로그램(Fusion 360) 튕김 문제 0%, 백그라운드 1초 초고속 검증.
  2. 학술 최신 SOTA 반영: 2025–2026년 가장 주목받는 VLM Closed-Loop Visual Feedback 아이디어를 실제 작동 시스템으로 구현.
  3. 실용적 호환성: STEP 파일 내보내기로 실제 산업 표준 CAD들과 100% 연동.
